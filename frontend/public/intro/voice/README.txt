NABA INTRO NARRATION
====================
Make each line in CapCut (Text to speech), export it as MP3, and save it in THIS folder
with the exact file name below. The intro plays these automatically when the speaker
button is on. A missing file falls back to the browser's robotic voice for that line.

Tips: pick one voice for all 8 lines, a calm, clear, confident tone. Keep every clip a
little SHORTER than its time window so it never overlaps the next line.

cue-0.mp3   (about 2.8 s)  Earth is changing every day.
cue-1.mp3   (about 2.9 s)  Optical satellites observe it using light.
cue-2.mp3   (about 2.9 s)  But clouds block that light, and data is lost.
cue-3.mp3   (about 2.1 s)  NISAR changes that.
cue-4.mp3   (about 3.3 s)  NISAR, a NASA-ISRO radar satellite, sees through clouds.
cue-5.mp3   (about 5.1 s)  Its microwaves pass through clouds, day or night, and measure the ground.
cue-6.mp3   (about 4.1 s)  It detects ground changes of just a few centimetres.
cue-7.mp3   (about 3.7 s)  This turns radar into Earth's news, before it breaks.

Pronunciation hint for TTS: write "Naba" as "Nah-bah" and "NISAR" as "Nye-sar" if it mispronounces.
